## Įrankiai

- [IntelliJ IDEA](https://www.jetbrains.com/idea/) – projektui atidaryti, paleisti ir testuoti; reikia Java 21.
- [SoapUI](https://www.soapui.org/) – WADL ir REST užklausoms.
- [APIMATIC Transformer](https://www.apimatic.io/transformer) – WADL konvertavimui į OpenAPI.
- [Swagger Editor](https://editor.swagger.io/) – OpenAPI peržiūrai.
- [Postman](https://www.postman.com/) – REST užklausoms.
