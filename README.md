# Studentų JAX-RS REST paslauga

Tai trečiosios „Web services“ užduoties projektas. Reikia **Java 21**; Gradle įdiegti nereikia.

```bash
./gradlew check
./gradlew run
```

Kol antra komanda veikia, naršyklėje atidarykite [studentus](http://localhost:8081/api/students) arba [WADL](http://localhost:8081/api/application.wadl). Sustabdykite `Ctrl+C`.

Išsamūs lietuviški paaiškinimai ir SoapUI, Swagger Editor bei Postman žingsniai yra [PAAISKINIMAS-LT.md](PAAISKINIMAS-LT.md).
